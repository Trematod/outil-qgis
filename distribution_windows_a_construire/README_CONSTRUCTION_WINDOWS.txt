DOSSIER DE PREPARATION DU PACKAGE WINDOWS

Ce dossier contient le code et les scripts necessaires pour construire le package portable.

Sur un ordinateur Windows de developpement :

1. Double-cliquez sur build_portable_windows.bat.
2. Attendez la fin de la construction.
3. Le dossier distribution_windows sera cree dans ce dossier.
4. Compressez ensuite ce dossier distribution_windows.

Le build necessite Python sur l'ordinateur qui construit le package.
Python ne sera pas necessaire sur les ordinateurs des collegues.
