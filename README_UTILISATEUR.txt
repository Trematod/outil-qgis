PREPARATION DES DONNEES

1. Double-cliquez sur start.bat.
2. Attendez l'ouverture du navigateur.
3. Utilisez l'application dans le navigateur.
4. Pour fermer l'application, fermez la fenetre noire PreparationDonnees.

Le lecteur reseau S: doit etre connecte et accessible avant le traitement.
Sur Linux, montez le partage reseau puis adaptez les chemins dans configuration.json
avant le premier lancement. Par exemple, utilisez /mnt/serma/... au lieu de S:\\....
Ne supprimez pas les autres fichiers du dossier.
