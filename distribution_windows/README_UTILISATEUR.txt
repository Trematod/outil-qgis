PREPARATION DES DONNEES - WINDOWS

PREMIER LANCEMENT

1. Decompressez le ZIP dans un dossier local.
2. Verifiez que le lecteur reseau S: est connecte.
3. Double-cliquez sur start.bat.
4. Le navigateur s'ouvre sur http://127.0.0.1:8000.

Lors du premier lancement, Python cree un environnement local et installe les dependances.
Une connexion Internet est necessaire uniquement lors de cette premiere installation.

ARRET

Double-cliquez sur stop.bat.

DEPANNAGE

Les chemins serveur inaccessibles sont signales au demarrage et dans l'interface.
Si le serveur ne demarre pas, consultez application.log.

Python 3 doit etre installe sur l'ordinateur.
